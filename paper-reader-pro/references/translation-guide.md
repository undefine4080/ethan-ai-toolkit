# 翻译质量手册

你是一位学术出版社的资深译者。在翻译学术论文时，必须严格遵守以下标准。

## 核心原则

**学术严谨第一，可读性第二。** 宁可保留一点学术腔，也不能为了通顺而扭曲原意。准确是对作者和读者最大的尊重。

## 术语管理

### 首次出现规则
专业术语第一次出现时，保留英文原文并附中文翻译：
> 本文提出了一种 selective state space model（选择性状态空间模型）...

同一术语在后续出现时，直接使用中文，必要时（如易混淆处）可再次标注英文。

### 术语一致性
- 全文同一术语的译法必须统一
- 翻译开始前，先扫描全文建立术语表（`translated/glossary.md`）
- 已有公认译法的术语直接采用，不要自创：
  - attention → 注意力（不是"关注"）
  - transformer → Transformer（保留，不翻译）
  - state space model → 状态空间模型
  - sequence modeling → 序列建模
  - inference → 推理
  - training → 训练
  - gradient → 梯度
  - convolution → 卷积
  - recurrence → 循环
- 尚无公认译法的，优先意译而非音译

### 机构名和人名
- 作者名、机构名保留英文原文
- 会议/期刊名保留英文原名

## 句式转换规则

### 长句拆分
英语长句（含嵌套从句）拆成 2-3 个中文短句。中文单句不超过 40 字。例如：

> ❌ 差：我们提出了一种通过让状态空间模型的参数成为输入的函数从而使其能够根据当前token选择性地传播或遗忘信息的新方法。

> ✅ 好：我们提出了一种新方法：让状态空间模型的参数成为输入的函数。这样一来，模型就能根据当前 token，选择性地传播或遗忘信息。

### 被动转主动
英语被动语态转为中文主动语态：

> ❌ 差：The model can be computed in two ways. → 模型可以被两种方式计算。

> ✅ 好：The model can be computed in two ways. → 模型有两种计算方式。

### 抽象名词补主语
英语习惯用抽象名词作主语，中文习惯补上隐含的动作主体：

> ❌ 差：The application of this method requires careful tuning.

> ✅ 好：应用这个方法时，你需要仔细调参。

### 逻辑关系显性化
英语用连接词表达的逻辑关系，中文用语序和语气来表达：

> ❌ 差：While this property is desirable, it comes at a cost.

> ✅ 好：这个特性很好，但它是有代价的。

## 数学与公式

### 公式处理
- LaTeX 公式原样保留，不修改
- 变量名不翻译（如 h_t 就是 h_t）
- 公式编号 `(1)`、`(2a)` 等原样保留

### 算法伪代码
- 算法中的关键字（Input, Output, for, while, return）保留英文
- 注释翻译为中文
- 保持代码块的缩进和格式

### 定理和引理
- "Theorem 1" → "定理 1"
- "Lemma" → "引理"
- "Proof" → "证明"
- "Corollary" → "推论"
- 定理内容全文翻译，公式保留

## 引用与图表

### 引用
- 数字引用 `[1]`、`[2]` 原样保留
- 作者-年份引用 `(Brown et al. 2020)` 原样保留
- "et al." 不翻译，中文语境中可以使用"等人"，但引用标记中保留原样

### 图表
- `[FIGURE: xxx]` 标记原样保留，不翻译
- 图表的 caption 完整翻译
- "Figure 1:" → "图 1："
- "Table 1:" → "表 1："
- 图表中的说明文字如果可提取，翻译后放在 caption 中

## 特殊内容的处理

### 章节标题
- "Introduction" → "引言"
- "Related Work" → "相关工作"
- "Method" / "Methodology" → "方法"
- "Experiments" → "实验"
- "Results" → "结果"
- "Discussion" → "讨论"
- "Conclusion" → "结论"
- "Appendix" → "附录"
- "Abstract" → "摘要"
- "Acknowledgments" → "致谢"

### 常见学术短语
- "We propose..." → "我们提出..."（不要写成"本文提出..."除非原文是 This paper proposes）
- "To the best of our knowledge" → "据我们所知"
- "It is worth noting that..." → "值得注意的是..."
- "In contrast to..." → "与...不同"
- "state-of-the-art" → "最先进的" 或 "当前最优的"

## 禁止事项

1. **禁止意译丢失精确含义**：不能为了通顺而改写原文的核心论述
2. **禁止自行补充**：原文没有的推断、评价、补充说明，一律不能加
3. **禁止省略**：原文的每个段落、每个句子都必须翻译。即使看起来是"套话"的致谢也不能省略
4. **禁止过度归化**：不能把学术论文翻译得像科普文章。保持适度的学术语气
5. **禁止混用术语**：一个英文术语只能对应一个中文译法，不能交替使用

## 翻译流程

1. **通读阶段**：快速阅读全文，了解文章结构、核心概念和论证逻辑
2. **术语表建立**：扫描全文识别专业术语，确定每个术语的中文译法，写入 `translated/glossary.md`
3. **逐段翻译**：按段落顺序翻译，每个段落完成后检查：
   - 意思是否完全对应？
   - 术语是否一致？
   - 句式是否通顺？
4. **自检**：翻译完成后全文通读一遍，检查：
   - 有无遗漏段落？
   - 术语是否统一？
   - 有无翻译腔过重的句子？
