# 文件结构规范

每篇文章都需要在当前目录下创建一个子目录作为工作目录，命名格式：`article-{文章标题}-{YYYYMMDD}/`

## 目录结构

```
article-{文章标题}-{日期}/
├── outline.md          # 选题确认单 + 大纲（阶段 1 输出）
├── materials/          # 素材目录
│   ├── source-01.md    # 单条素材（含来源、时间、摘要、引用）
│   ├── source-02.md
│   ├── ...
│   └── summary.md      # 素材汇总报告（阶段 2 输出）
├── draft.md            # 初稿（阶段 3 输出）
├── checklist.md        # 质检清单（阶段 4 输出）
└── [正式文章标题].md            # 终稿（阶段 5 输出）
```

## 单条素材文件格式

```markdown
# 素材标题

- **来源 URL**：___
- **发布时间**：___
- **来源类型**：官方文档 / 学术论文 / 行业报告 / 媒体文章 / 个人博客

## 核心摘要
（200字以内，AI 提炼）

## 关键引用
> 原文引用1（可直接用于文章的数据、观点、表述）

> 原文引用2

## 与本文的关联
（这条素材支撑大纲中的哪个部分）
```

## 工作目录位置

- 默认在用户当前工作目录下创建。如用户有指定位置，以用户指定为准。
- 编写文章过程中所创建的文件必须要收拢在工作目录中，不允许随意位置存放。
