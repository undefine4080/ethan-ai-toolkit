## 使用时的注意

1. **不要把模板里的 `<...>` 占位符留在最终报告里**。每一处都要替换成实际内容或明确说明"无"。
2. **每条问题的 ID**（C1、M1、m1）用于在对话和文件之间相互引用，保持唯一。
3. **Critical 严格 3 条上限**。超过必须降级或合并。
4. **报告写完后**，对话里只给：总体评价一句话 + Critical 数量 + 文件路径。不要贴完整报告。
