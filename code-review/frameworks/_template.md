# Framework 文档模板

**新增一门语言/框架时，复制这份文件为 `frameworks/<name>.md`，然后按下面的结构填充。**

这份模板的存在本身就是在约束：新增语言**只改自己这份文件**，不动 SKILL.md，不动 principles/。

---

## 写作建议

1. **只写 framework-specific 的东西**。通用的架构/简洁/可读/范式原则放在 `principles/`，这里不要重复。
2. **举具体的代码信号**。"看到 `useEffect([])` 里有异步函数"比"注意副作用的正确性"有用得多。
3. **注明版本**。框架演进快，一个反模式可能在旧版本是标准做法、在新版本已过时。
4. **保持克制**。不要把教程写在这里。只写**评审时需要判断的点**。
5. **如果内容超过 300 行**，考虑拆分到 `frameworks/<name>/` 子目录，主文件放导航。
